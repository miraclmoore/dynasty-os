Copy rationale:

- "Reload App" — specific verb + noun. Maps to `window.location.reload()` in the recovery handler.
- Error detail toggle — shows `error.message` and `error.stack` behind a chevron. Accessible to developers without alarming users.

## Phase-Specific: Error Boundary Component Design

### Component: `ErrorBoundary`

**Type:** React class component (required — React error boundaries must use `componentDidCatch` / `getDerivedStateFromError`; hooks cannot catch render errors).

**File:** `apps/desktop/src/components/ErrorBoundary.tsx`

**Usage in App.tsx:** Wrap `<PageContent />` — the entire routed page tree — so any page-level render crash shows the fallback instead of a blank white screen.

---

### Visual Design

**Outer container:**
```
className="flex h-[calc(100vh-40px)] items-center justify-center bg-gray-900"
```
Matches the existing dashboard layout container exactly. Uses the same `h-[calc(100vh-40px)]` to account for the TickerBar at the bottom.

**Error card:**
```
className="bg-gray-800 border border-red-900/50 rounded-xl p-8 max-w-md w-full mx-4 text-center"
```
- `bg-gray-800` — secondary surface, same as narrative/record cards throughout the app.
- `border-red-900/50` — muted red border signals error without being alarming. Same opacity pattern as SeasonRecapPage's `border-red-700/50`.
- `rounded-xl p-8` — matches DynastyCard's `rounded-xl p-5` convention; extra padding (p-8) for a full-page-level message.
- `max-w-md` — 448px, readable line length for body copy.

**Error icon:**
Inline SVG warning triangle, `className="w-12 h-12 text-red-400 mx-auto mb-4"`. No external icon library import needed — keeps the error boundary dependency-free.

**Heading:**
```
className="font-heading font-bold text-2xl text-white mb-2"
```
"Something went wrong." — 24px Oswald bold. Matches empty-state heading pattern in DashboardPage (`text-gray-300 font-semibold text-lg`), elevated slightly to `text-white` because this is a blocking error.

**Body text:**
```
className="text-gray-400 text-sm leading-relaxed mb-6"
```
"An unexpected error occurred and this part of the app could not load. Reload the app to recover — your dynasty data is safe."

**Recovery CTA button:**
```
className="w-full px-4 py-2 bg-red-700 hover:bg-red-600 text-white text-sm font-bold rounded-lg transition-colors mb-4"
onClick={() => window.location.reload()}
```
- `bg-red-700 hover:bg-red-600` — matches the "Try Again" button in SeasonRecapPage exactly.
- `w-full` — full-width within the card for easy click target.

**Error detail toggle (collapsed by default):**
```
className="text-xs text-gray-500 hover:text-gray-400 underline cursor-pointer transition-colors"
```
Clicking reveals a `<pre>` block with `error.message` and optionally `error.stack`:
```
className="mt-2 text-left bg-gray-900 border border-gray-700 rounded-lg p-2 text-xs text-gray-400 font-mono overflow-auto max-h-32"
```

---

### Layout Summary (visual hierarchy, top to bottom inside card)

1. Warning triangle SVG icon — `text-red-400`, 48px, centered, 16px margin-bottom
2. Heading — "Something went wrong." — `text-2xl font-bold font-heading text-white`, 8px margin-bottom
3. Body — one paragraph, `text-sm text-gray-400 leading-relaxed`, 24px margin-bottom
4. "Reload App" button — full-width, `bg-red-700`, 16px margin-bottom
5. "Show error details" toggle — `text-xs text-gray-500`, underlined, collapsed by default
6. Detail pre block — conditionally rendered, monospace, `bg-gray-900`, max-height 128px with overflow-auto

---

### Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Render error thrown anywhere under `<PageContent>` | ErrorBoundary catches via `getDerivedStateFromError`, renders fallback UI |
| "Reload App" click | `window.location.reload()` — full page reload, clears React state |
| "Show error details" click | Toggles local `showDetails` state; reveals `<pre>` block |
| Repeated crashes | No retry loop — reload is the only recovery path |

**State:** ErrorBoundary holds `{ hasError: boolean, error: Error | null, showDetails: boolean }`. `showDetails` is local UI state only.

---

### Accessibility

- Error card is `role="alert"` — screen readers announce the error immediately on render.
- Warning icon has `aria-hidden="true"` — decorative only.
- "Reload App" button has no disabled state — always actionable.
- "Show error details" uses `aria-expanded` to communicate toggle state.
