## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-01-01 | Tampering | `updateRecruit` Dexie call | accept | TypeScript `Partial<Omit<Recruit, 'id' \| 'dynastyId' \| 'classId' \| 'createdAt'>>` constrains writable fields at compile time; immutable identity fields cannot be mutated through this path. |
| T-24-01-02 | Tampering / XSS | AddPlayerModal initial-value props | accept | Values are bound via React state into `<input>` `value` attributes; React escapes text nodes/values automatically. No `dangerouslySetInnerHTML` is introduced. |
| T-24-01-03 | Information Disclosure | Toast error string on revert | accept | Error message is a generic user-facing string ("Could not save recruit. Please try again."); the underlying `err` object is re-thrown to the caller but never rendered to the DOM. |
| T-24-01-04 | Repudiation | Optimistic update without server log | accept | Local-first app, single-user dynasty per device. `updatedAt` timestamp is stamped server-side (Dexie write) on every update. |
</threat_model>
