```typescript
const MADDEN_YEARS = [26, 25, 24] as const;

async function discoverFranchiseFiles(): Promise<string[]> {
  const found: string[] = [];
  const seen = new Set<string>();

  let docDir = '';
  let tmpDir = '';
  try { docDir = await documentDir(); } catch { docDir = ''; }
  try { tmpDir = await tempDir(); } catch { tmpDir = ''; }

  const candidateDirs: string[] = [];
  for (const year of MADDEN_YEARS) {
    if (docDir) {
      try { candidateDirs.push(await join(docDir, `Madden NFL ${year}`, 'saves')); } catch { /* ignore */ }
      try { candidateDirs.push(await join(docDir, `Madden NFL ${year}`, 'Saves')); } catch { /* ignore */ }
    }
    if (tmpDir) {
      try { candidateDirs.push(await join(tmpDir, `Madden NFL ${year}`)); } catch { /* ignore */ }
    }
  }
  // Legacy autosave path also documented as the existing hint on the page
  if (tmpDir) {
    try { candidateDirs.push(await join(tmpDir, 'Franchise')); } catch { /* ignore */ }
  }

  for (const dir of candidateDirs) {
    try {
      const present = await exists(dir);
      if (!present) continue;
      const entries = await readDir(dir);
      for (const entry of entries) {
        if (!entry.isFile) continue;
        if (!entry.name?.toLowerCase().endsWith('.frs')) continue;
        try {
          const fullPath = await join(dir, entry.name);
          if (seen.has(fullPath)) continue;
          seen.add(fullPath);
          found.push(fullPath);
        } catch { /* ignore */ }
      }
    } catch {
      // dir not accessible, permission missing, or readDir threw — continue silently
    }
  }
  return found;
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS filesystem → Tauri WebView (frontend) | Directory entries from user's Documents and Temp; readDir results crossed into JS context |
| Discovered .frs path → app state | User-controlled file path becomes the active save target on chip click |
| Tauri capability gate → plugin-fs | ACL governs which paths can be enumerated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-02-01 | Elevation of Privilege | Tauri fs scope grant | mitigate | Use targeted `fs:scope-document-recursive` + `fs:scope-temp-recursive` instead of `fs:scope-home-recursive`. Documents and Temp are the only directories Madden writes save files to. Acceptance criteria explicitly forbids `fs:scope-home-recursive` (verified absent in Task 1 verify) |
| T-23-02-02 | Tampering | Path traversal via discovered names | mitigate | All paths are constructed via `@tauri-apps/api/path` `join()` — never string concatenation; entries from readDir are filtered to `entry.isFile && entry.name.toLowerCase().endsWith('.frs')` so non-files (symlinks, directories) cannot escape; Tauri's scope grants enforce that `readDir` cannot escape the granted recursive root |
| T-23-02-03 | Denial of Service | discoverFranchiseFiles on broken FS | mitigate | Every `documentDir()`, `tempDir()`, `join()`, `exists()`, `readDir()` call is wrapped in try/catch; helper returns `[]` on any failure; useEffect uses fire-and-forget IIFE so a slow or failed discover never blocks render. Page renders normally with empty chip row when no files found |
| T-23-02-04 | Information Disclosure | Discovered paths shown in UI | accept | File paths are displayed only to the user who owns them in their own Documents/Temp; no transmission off-device. Hover `title={filePath}` shows the full path for the same user — no privacy concern |
| T-23-02-05 | Tampering | User clicks chip with adversarial path | accept | Adversary would need pre-existing write access to user's Documents or Temp to plant an .frs; at that point, full local-machine compromise is already in play. madden-franchise library robustness against malformed binaries is the existing mitigation (Plan 1's threat T-23-01-01/02 covers sidecar-side parse hardening) |
| T-23-02-06 | Spoofing | File extension filter | mitigate | Filter is `entry.name.toLowerCase().endsWith('.frs')` — case-insensitive but strict suffix check. `validateSaveFile` (existing) still runs the full madden-franchise validation before extraction; chip click does not auto-validate or auto-extract — user explicitly clicks "Validate File" next |
</threat_model>
